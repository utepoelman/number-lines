Nugget's Number Lines

Draw a number line that shows this whole range. Select a dot where the line crosses a grid line and type a number, then press Enter. Label a second dot and the rest of the line fills in. Solve ten number lines on your own to earn a certificate from Nugget.

Using a suggested scale is fine for learning, but that number line won't count towards your certificate.

Each question has a blank 30-square grid. Students draw the number line, mark the grid lines and write the numbers in by hand.
